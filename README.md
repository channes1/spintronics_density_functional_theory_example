# spintronics_density_functional_theory_example

Study of elastic and inelastic electron tunneling in a Gold Wire Nanojunction having molecules of gold, sulfur, nickel, and manganese. This was done using density functional theory, quantum espresso and visualization is using Avogadro. 

# Figure-by-Figure Reproduction of

P. Balasubramanian, Deepika G. T., and A. Sen,
Elastic and Inelastic Electron Tunneling in Doped Gold Wire Nanojunctions,
IEEE ICANMEET 2013

This repository contains the input files, geometries, and workflows
required to reproduce every figure in the paper.

The purpose is scientific reproducibility and independent verification
of the published calculations.
